# Pong

Open [`pong.html`](pong.html) directly in a desktop browser. The game runs offline and needs no installation, server, build, or external assets.

## Controls

- Up / Down arrows: move the left paddle
- Space: start or restart
- P: pause or resume

## Gameplay check

Open `pong.html?test` in a browser to run the dependency-free checks for paddle bounds, wall and paddle collisions, bounce angle, ball speed cap, scoring, CPU movement, pause/resume, winning, and restart. The page displays each result.
